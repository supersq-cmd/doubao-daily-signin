# doubao-daily-signin — 豆包每日自动签到领额度

一个可安装的豆包技能（Skill）：每天自动完成豆包「每日签到」，领体验额度（平日 +200，周一翻倍 +400），并回报连续签到天数。

**不是在网页上签到。** 它走的是豆包电脑客户端自己的登录态——把命令交给豆包工作/豆包电脑版的 Agent，它在客户端内置浏览器里调用活动接口，你不需要装浏览器插件、不用抓 cookie。

## 适合谁

- 装了豆包电脑客户端的个人账号用户
- 想要"每天自动签一次、不记得也没关系"的人

不适合：企业账号 / 飞书账号（没有这条签到任务）；不用客户端的人。

## 安装（三选一）

### 方式 A：一句话让豆包装（最简单）

把本文件夹拖进豆包对话，然后说：

> 把 doubao-daily-signin 装成我的技能

### 方式 B：脚本安装（Windows）

```powershell
# 在解压后的文件夹里执行
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

脚本会把技能复制到豆包的技能目录，并提示你重启客户端。

### 方式 C：手动复制

把整个 `doubao-daily-signin` 文件夹放到：

```
%LOCALAPPDATA%\Doubao\User Data\Default\.doubao\agent_mode\workspace\.user_skills\
```

最终路径形如 `...\.user_skills\doubao-daily-signin\SKILL.md`。放好后重启豆包客户端。

## 使用

在对话里说任意一句：

- 「豆包签到」
- 「今天签到了吗」
- 「用 doubao-daily-signin 签到」

它会回一句话：**日期 · 是否已签到 · 领取多少额度 · 连续第几天 · 累计额度**。

## 设置每天几点自动签到

时间存在技能根目录 `config.json`：

```json
{ "signin_time": "07:20", "timezone": "Asia/Shanghai", "cron_job_id": null }
```

直接对豆包说「每天 8 点签到」即可，它会改 `config.json` 并同步一条每日定时任务。也可以自己跑：

```bash
python scripts/schedule.py --show        # 查看
python scripts/schedule.py --set 07:40   # 修改
```

定时任务默认 **07:20**（避开 7:30-10:00 的任务高峰）。前提是触发时豆包客户端在运行且保持登录。

## 常见问题

**提示"未登录"**：在豆包里重新登录一次，再让它签到。

**提示"当前账号无签到任务"**：活动未开放或企业/飞书账号，没有这条任务。

**提示 710010702 / 接口报错**：豆包客户端升级后版本号校验会变，脚本会按本机 `Doubao.exe` 的版本自动派生并回退重试；仍失败就是接口改了，等更新。

**会不会重复领 / 扣额度**：不会。服务端幂等，重复执行返回"已签到"，额度不重复发放也不扣减。
